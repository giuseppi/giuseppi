## 🏀 Projects I'm proud of

- **[Clutch](https://v0-clutch-web.vercel.app/)** 🏆 *1st Place, 2026 UCI ICS Project Expo*: an iPhone app that keeps score of pickup basketball games in real time. It runs custom YOLO detectors on device at 20 FPS and tracks players and the ball through occlusions with ByteTrack and gravity-aware Kalman filters. I led the team, and we hand-labeled nearly 2,000 frames to train it.
- **JIT Expression Compiler**: a just-in-time compiler in C that turns math expressions into C, compiles them into a shared library, and runs them in-process.
